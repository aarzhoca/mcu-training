# Video Reference — Nuvoton NuMicro Level 1 Workshop

Official Nuvoton workshop series (17 videos), applicable to NuMaker boards including the M031SD. Each peripheral has two videos — a **concept** talk and a **Sample Code** walkthrough. Watch concept → sample code → then the matching TRM chapter for register-level detail, before starting that week's TASKS.md.

**Full playlist:** https://www.youtube.com/playlist?list=PL0M6qIz4YrQ0zgeG0TDTQ1kUeiiXaL32p

## How to use
Watch concept + sample code (~15–20 min combined) *before* starting that week's BSP sample — faster way in than reading the TRM cold. Still do the TRM reading afterward for register-level detail the videos skip.
